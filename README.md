# Node API Basics

A basic Express.js API project from database, web, and networking coursework. It demonstrates setting up a small Node server and defining simple API behavior.

## Tech Stack

- Node.js
- Express.js
- JavaScript

## Features

- Express server setup
- Simple API structure
- Package configuration
- Dependency lock file included for repeatable install

## How to Run

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

## What I Learned

- Creating a Node.js project
- Installing and using Express
- Basic API/server structure
- Managing dependencies with `package.json`
